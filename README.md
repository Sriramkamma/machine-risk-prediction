# Machine Risk Prediction

This project is a web application for managing machine data and predicting machine risk.

The application allows users to add machine fields, create machine records and check the risk of a machine.

## Technologies Used

- React + Vite
- Node.js + Express
- Supabase PostgreSQL
- Python
- FastAPI
- Random Forest
- Scikit-learn
